> Inspired by Timur Brachkow's [How I work with AI](https://www.brachkow.com/notes/how-i-work-with-ai/).

## Model

Claude Opus 5.5 ftw.

Reasoning effort: medium.

## Harness

[Claude Code](https://claude.com/claude-code).

I'm teaching myself to think of the harness separately from the model.

## Interface

[T3 Code](https://t3.codes). [This video from Theo](https://youtu.be/uLGxb4F3SyI) sold me on it.

I like the inbox-zero chats and built-in remote work. Icons on projects, links and files are a nice touch.

## Writing code by hand

Rarely these days. When I do, I switch between [Cursor](https://cursor.com), [VS Code](https://code.visualstudio.com) and [Sublime Text](https://www.sublimetext.com). Annoying, should pick one.

## Git

In personal projects I gave up and let the harness commit and push on its own. Apparently it's much faster

In work projects I still check diff before commit in [GitHub Desktop](https://desktop.github.com).

## Working in parallel

I don't like worktrees, so I don't work on one project in parallel. It's a bottleneck, but fine for now.

## Skills

/grilling from Matt Pocock's AI Hero course. After a long Q&A, the agent and I understand the task much better. I also like that it recommends an answer to each question.

My own skill for renaming chats the way I like. Handy shortcut for a prompt.

## MCP

[Cloudflare MCP](https://github.com/cloudflare/mcp-server-cloudflare), read-only. Easier than clicking around the Cloudflare dashboard.

Turns out this is really convenient. Next I want to make an MCP for my own project, so the agent can do things there on my behalf.

## On the go

My code lives on a VPS. I found [Tailscale](https://tailscale.com), and working from my iPhone directly on the VPS is now super simple.

## Learning

Going through [AI Hero](https://www.aihero.dev), Matt Pocock's course.

---

This is how I work right now. Things will change, and I'll update this note when they do.
